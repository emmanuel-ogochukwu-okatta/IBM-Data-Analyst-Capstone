# IBM Data Analyst Capstone Project

Analysis of the Stack Overflow Developer Survey: which technologies developers use today and want to use next.

## Tools
Python (pandas), JupyterLab, IBM Cognos Analytics, PowerPoint

## What I did
- Cleaned the survey data and split multi-answer columns (separated by ";") so each language, database, platform and framework is counted once
- Built a 3-tab Cognos dashboard: Current Technology Usage, Future Technology Trend, Demographics
- Wrote a 17-slide report with findings and implications

## Key findings
- JavaScript, SQL and HTML/CSS lead current usage; JavaScript, SQL and TypeScript lead future interest
- PostgreSQL is the top database now and in future demand (Redis is rising)
- AWS leads cloud platforms; React and Node.js lead web frameworks
- Most respondents are 25-44 years old; the largest education group holds a Bachelor's degree
